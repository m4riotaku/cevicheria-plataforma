# Modelo de Negocio Cevichería (UNSM - 2026)
Proyecto universitario para la asignatura de "lenguaje de programación III" 
## Guía de instalación
### Instalación de dependencias
- [openjdk21](https://www.oracle.com/java/technologies/downloads/#java21)
- [git](https://git-scm.com/install/)
- [maven](https://maven.apache.org/download.cgi)
### Clone este repositorio
1. clone el repositorio en una carpeta/directorio de su preferencia
```
git clone https://github.com/m4riotaku/cevicheria-platform.git
```
2. entrar en la carpeta del repositorio
```
cd cevicheria-platform
```
3. instalar paquetes e iniciar la aplicación
```
mvn clean spring-boot:run
```
